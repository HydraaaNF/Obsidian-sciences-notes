# Loi
Soit $\lambda > 0$.  $X \sim \mathcal{P}(\lambda)$ si $X(\Omega) = \mathbb{N}$, avec : $$\forall k \in \mathbb{N}, \mathbb{P}(X = k) = e^{-\lambda}\frac{\lambda^k}{k!}$$
# Propriétés
Soit $X \sim \mathcal{P}(\lambda)$, alors
- $\mathbb{E}(X) = \lambda$
- $\mathbb{V}(X) = \lambda$
- $G_X(z) = e^{\lambda (z-1)}$
