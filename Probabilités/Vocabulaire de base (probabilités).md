# Définition
On étudie des **objets équivalents** sur lesquels on observe des **variables** :
- objet = pièce de monnaie ; variable = face sur laquelle elle tombe
- objet = produit manufacturé ; variables = dimensions, poids
- objet = expérience de classification ; variable = taux d'erreur

- **Population** : un groupe d'objets équivalents
- **Individu** : un objet du groupe
- **Échantillon** : un sous-ensemble de la population (donné ou choisi)
- **Variable** : caractéristique décrivant un individu

# Types de variables
- **numérique** : discrète ou continue
- **catégorielle** : nominale (sans ordre) ou ordinale (avec un ordre)

# Événement
Une **assertion logique** relative à l'expérience (ex : "le résultat sera supérieur à 10"), le plus souvent vue comme un sous-ensemble de $\Omega$.

Un **événement élémentaire** est un sous-ensemble de $\Omega$ contenant un seul élément.

# Événements incompatibles
Deux événements $A$ et $B$ sont dits **incompatibles** si la réalisation de l'un exclut celle de l'autre, c'est-à-dire si $A \cap B = \emptyset$.

# Remarque
Un [[Système complet d'évènements|système complet d'évènements]] est en particulier une famille d'événements incompatibles deux à deux (et dont la réunion vaut $\Omega$).
