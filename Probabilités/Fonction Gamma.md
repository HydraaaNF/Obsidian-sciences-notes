# Définition
Pour $x > 0$, la fonction Gamma d'Euler est définie par l'intégrale

$$\Gamma(x) = \int_0^{+\infty} t^{x-1} e^{-t} \, dt$$

# Propriétés
* Relation de récurrence : $\Gamma(x+1) = x \, \Gamma(x)$
* Lien avec la factorielle : $\Gamma(n) = (n-1)!$ pour tout $n \in \mathbb{N}^*$
* Valeurs particulières : $\Gamma(1) = 1$, $\Gamma\!\left(\dfrac{1}{2}\right) = \sqrt{\pi}$
* Formule de réflexion : $\Gamma(x)\,\Gamma(1-x) = \dfrac{\pi}{\sin(\pi x)}$ pour $x \notin \mathbb{Z}$
