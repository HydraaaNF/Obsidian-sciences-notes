# Propriétés
Les t-normes et t-conormes généralisent la conjonction et la disjonction booléennes : sur les valeurs $0$ et $1$, elles redonnent la table de vérité usuelle.

| Égalité | Justification |
| --- | --- |
| $\top(0, 1) = \top(1, 0) = \top(0, 0) = 0$ | $0$ est absorbant pour toute t-norme |
| $\top(1, 1) = 1$ | $1$ est neutre pour toute t-norme |
| $\bot(0, 1) = \bot(1, 0) = \bot(1, 1) = 1$ | $1$ est absorbant pour toute t-conorme |
| $\bot(0, 0) = 0$ | $0$ est neutre pour toute t-conorme |

# Remarque
Voir [[Norme triangulaire]] et [[Conorme triangulaire]] pour les éléments neutre et absorbant.
