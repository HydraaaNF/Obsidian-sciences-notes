# Définition
Un **opérateur de compromis** est un opérateur de moyenne qui exprime un **compromis** entre ses arguments. Il n'a **pas de contrepartie** dans un cadre booléen.

# Propriétés
On peut utiliser :
- des **moyennes simples** : moyenne arithmétique, géométrique, harmonique, … ;
- des **moyennes pondérées**, où une importance est affectée à chaque argument (c'est-à-dire à chaque ensemble flou) : [[Moyenne pondérée d'ensembles flous]] et [[Opérateur OWA]].
