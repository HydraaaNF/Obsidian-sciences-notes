# Définition
Deux approches sont possibles pour l'inclusion $\subset$ :
- la **définir** lorsque les opérandes sont des ensembles flous : c'est l'[[Inclusion de Zadeh]] ;
- la voir comme un **opérateur graduel**, quel que soit le type des opérandes (flous ou non), qui renvoie un degré $\deg(E \subset F) \in [0, 1]$.
