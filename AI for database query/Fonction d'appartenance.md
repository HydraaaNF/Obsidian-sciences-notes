Un [[Ensemble flou]] $E$ est associé à une **fonction d'appartenance**
$\mu_E : X \to [0, 1]$.

$\mu_E(x)$ est le **degré d'appartenance** de $x$ à $E$ : il indique dans quelle
mesure $x$ est un élément de $E$, c'est-à-dire dans quelle mesure $x$ satisfait
le concept associé à $E$.

### Trois situations
- $\mu_E(x) = 0$ : **non-appartenance complète**
- $\mu_E(x) = 1$ : **appartenance complète**
- $0 < \mu_E(x) < 1$ : appartenance **partielle** — plus le degré est proche de
  $1$, plus $x$ est satisfaisant

### Modes de définition
- Par une [[Fonction d'appartenance trapézoïdale]] dans le cas continu
- Par énumération dans le cas d'un [[Ensemble flou fini et discret]]

À comparer avec la [[Fonction caractéristique]] du cas classique.
