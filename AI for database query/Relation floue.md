# Définition
Une **relation floue** $r$ est une relation dont chaque n-uplet $t$ possède un **degré d'appartenance** $\mu_r(t) \in [0, 1]$, qui exprime dans quelle mesure $t$ satisfait le concept flou associé à $r$.

Une relation floue est ainsi un [[Ensemble flou]] de n-uplets. Son [[Support d'un ensemble flou|support]], noté $\operatorname{supp}(r)$, est l'ensemble des n-uplets de degré strictement positif.

# Remarque
Une relation classique est une relation floue dont tous les n-uplets ont le degré $1$.

Les relations floues sont manipulées par l'[[Algèbre relationnelle floue]].
