# Définition
Le **noyau** d'un [[Ensemble flou]] $E$ est l'ensemble classique des éléments qui appartiennent **complètement** à $E$ :

$$
\operatorname{noyau}(E) = \{x \in X \mid \mu_E(x) = 1\}
$$

# Propriétés
- Le noyau est la **coupe de niveau $1$** : $\operatorname{noyau}(E) = E_1$ (voir [[Coupe de niveau alpha]]).
- Dans le cas classique, $\operatorname{supp}(A) = \operatorname{noyau}(A) = A$.
- Le noyau est non vide si et seulement si $E$ est normalisé (voir [[Hauteur d'un ensemble flou]]).

# Exemple
Pour l'ensemble flou *young* de [[Logique floue]] : $\operatorname{noyau}(\text{young}) = [0, 30]$.

Pour $E = \{1/a,\; 0{,}7/c,\; 0{,}2/e,\; 0{,}3/f,\; 0{,}6/h,\; 0{,}7/j,\; 0{,}9/k\}$ : $\operatorname{noyau}(E) = \{a\}$.
