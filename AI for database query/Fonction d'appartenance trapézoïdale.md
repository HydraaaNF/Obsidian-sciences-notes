Une [[Fonction d'appartenance]] est fréquemment définie par une **fonction
trapézoïdale**, dont il existe trois types :

- **décroissante** — modélise *petit*, *bon marché*, *jeune*…
- **croissante** — modélise *grand*, *cher*, *âgé*…
- **croissante puis décroissante** — modélise *moyen*, *d'âge mûr*… ; ce dernier
  cas est défini par **4 seuils** $(a, b, c, d)$ :
  - croissance linéaire de $0$ à $1$ sur $[a, b]$
  - valeur constante $1$ sur $[b, c]$ — c'est le [[Noyau d'un ensemble flou]]
  - décroissance linéaire de $1$ à $0$ sur $[c, d]$
  - valeur $0$ ailleurs — le [[Support d'un ensemble flou]] est $]a, d[$
