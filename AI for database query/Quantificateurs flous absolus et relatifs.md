# Définition
- Un quantificateur **absolu** s'applique à un **nombre** (une quantité). Exemples : *une douzaine*, *environ 6*, …
- Un quantificateur **relatif** s'applique à une **proportion**. Exemples : *environ la moitié*, *presque tous*, *la plupart*, …

# Propriétés
En termes de fonctions d'appartenance :
- quantificateur absolu : $\mu_{Q_A} : \mathbb{N}\ (\text{ou } \mathbb{R}) \to [0, 1]$ ;
- quantificateur relatif : $\mu_{Q_R} : [0, 1] \to [0, 1]$.
