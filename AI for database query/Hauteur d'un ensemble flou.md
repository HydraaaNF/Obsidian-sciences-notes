# Définition
La **hauteur** d'un [[Ensemble flou]] $E$ est le degré d'appartenance maximal atteint sur l'univers (supposé fini) :

$$
\operatorname{hauteur}(E) = \max_{x \in X} \mu_E(x)
$$

# Propriétés
$E$ est dit **normalisé** si $\operatorname{hauteur}(E) = 1$, c'est-à-dire s'il existe au moins un élément appartenant complètement à $E$ : son [[Noyau d'un ensemble flou|noyau]] est alors non vide.

# Exemple
Avec $E = \{1/a,\; 0{,}7/c,\; 0{,}2/e,\; 0{,}3/f,\; 0{,}6/h,\; 0{,}7/j,\; 0{,}9/k\}$ : $\operatorname{hauteur}(E) = 1$, donc $E$ est normalisé.
