#dmv-visualization

# Définition

Manipuler une visualisation, c'est agir sur les données affichées dans la vue, selon trois actions :

- changer : modifier ce qui est montré ;
- sélectionner : désigner une partie des données pour la mettre en avant ou la détailler ;
- naviguer : se déplacer dans la vue ou dans la structure des données.

# Exemple

Un sunburst interactif répond au clic sur un secteur : le secteur est sélectionné et ses sous-parties se déploient dans un nouvel anneau, si bien que la sélection sert en même temps de navigation dans la hiérarchie.

# Remarque

La manipulation est la part visible de l'[[Interactivité de la visualisation]] : elle donne accès à la succession de vues qu'une figure statique ne peut pas offrir.
Elle répond à la troisième question du comment : voir [[Questions du comment en conception de visualisation]].
Une sélection prend tout son sens quand elle se répercute sur d'autres vues : voir [[Vues multiples coordonnées]], par exemple pour relier les catégories d'un [[Diagramme en ensembles parallèles]].
