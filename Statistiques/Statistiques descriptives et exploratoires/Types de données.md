# Définition
On observe une ou plusieurs variables sur une population d'individus. Les données peuvent être de nature différente :

- **catégorielles** : ordonnées (ex : niveau de satisfaction) ou non (ex : couleur), codées (par un entier) ou non
- **numériques** : la somme a un sens (contrairement aux catégorielles codées)
- **scalaires ou non** : une variable peut être à valeurs dans $\mathbb{R}$ (scalaire) ou dans un espace de plus grande dimension

# Interprétation
La provenance des données influence leur représentativité :
- données déjà disponibles (« elles sont là ») : peuvent ne pas être représentatives
- données dont on conçoit le recueil : on peut viser un échantillon représentatif (conception de bases de données, plan d'échantillonnage)
