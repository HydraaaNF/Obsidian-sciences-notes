# Définition
Pour un échantillon $x_1, \ldots, x_n$, la moyenne empirique est
$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$$

# Interprétation
Résumé de tendance centrale le plus courant, mais sensible aux valeurs aberrantes.

# Remarque
Ne pas confondre avec l'[[Espérance d'une variable aléatoire|espérance théorique]] $\mathbb{E}(X)$ : la moyenne empirique est calculée sur un échantillon observé, l'espérance est une propriété du modèle probabiliste sous-jacent.
