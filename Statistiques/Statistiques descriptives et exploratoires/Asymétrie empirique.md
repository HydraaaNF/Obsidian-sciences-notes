# Définition
Version empirique du [[Moment d'ordre k|moment]] d'ordre 3 normalisé (skewness), calculée sur un échantillon plutôt que sur une loi théorique.

# Interprétation
- distribution symétrique → asymétrie nulle
- queue plus lourde à gauche → asymétrie négative
- queue plus lourde à droite → asymétrie positive
