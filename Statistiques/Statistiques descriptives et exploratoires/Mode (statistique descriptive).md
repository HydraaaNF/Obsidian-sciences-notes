# Définition
Le mode d'une distribution est la valeur (ou l'intervalle, dans le cas d'un [[Histogramme]]) correspondant à un extremum local de la distribution — c'est-à-dire la valeur la plus fréquente.

# Interprétation
Une distribution peut avoir plusieurs modes (distribution multimodale), ce qui peut indiquer un mélange de sous-populations.

# Remarque
Pour une distribution parfaitement symétrique, mode = médiane = moyenne.
