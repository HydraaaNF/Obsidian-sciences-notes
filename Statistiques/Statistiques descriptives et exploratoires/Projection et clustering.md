# Définition

On observe des variables $X \in \mathbb{R}^p$. Lorsque $p$ est grand, deux familles d'approches permettent d'analyser les données :

- la **projection** : afficher les variables dans $\mathbb{R}^q$, avec $q \ll p$ ;
- le **clustering** : regrouper les observations.

# Interprétation

L'approche par projection comprend notamment :

- l'[[Analyse en composantes principales|analyse en composantes principales]] (ACP) ;
- l'[[Analyse discriminante linéaire|analyse discriminante linéaire]] (LDA) et les méthodes voisines ;
- l'analyse des correspondances ;
- l'[[Analyse factorielle]].

L'approche par clustering comprend notamment :

- les k-means et les méthodes voisines ;
- le clustering ascendant (bottom-up) ;
- le clustering spectral (spectral clustering).

Dans le plan, les observations se répartissent en un [[Nuage de points]] allongé selon une direction.
