# Définition

D'autres critères d'estimation de paramètres existent :

- le [[Critère d'information bayésien|critère d'information bayésien]] (BIC) ;
- la minimisation des erreurs de classification (MCE) : minimisation explicite, ou estimation fondée sur des réseaux de neurones ;
- le maximum d'entropie (Maxent) : choisir le modèle dont l'entropie est la plus grande possible ;
- l'information mutuelle maximale (MMI) ;
- etc.
