# Définition
Pour $p$ variables observées sur $n$ individus, la matrice de corrélation est la matrice $p \times p$ dont le coefficient $(i, j)$ est le [[Coefficient de corrélation de Pearson|coefficient de corrélation]] entre les variables $i$ et $j$.

# Interprétation
Résume en un seul tableau toutes les corrélations linéaires deux à deux entre les variables d'un jeu de données multidimensionnel. Base de départ pour l'[[Analyse en composantes principales]].
