# Définition
Une bonne projection linéaire pour l'[[Analyse en composantes principales|ACP]] vise à :
- préserver les distances entre individus
- maximiser la variance des données projetées
- maximiser l'inertie
- minimiser l'erreur des moindres carrés

# Interprétation
Ces quatre critères sont équivalents dans le cadre de l'ACP classique — ils motivent conjointement l'[[Algorithme de l'ACP]].
