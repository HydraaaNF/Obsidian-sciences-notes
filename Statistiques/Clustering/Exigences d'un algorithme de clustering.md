# Propriétés

Un [[Clustering|algorithme de clustering]] doit satisfaire les exigences suivantes :

- **Scalabilité** (scalability) : le comportement de l'algorithme lorsque la taille des données augmente, jusqu'aux [[Clustering de grands jeux de données|grands jeux de données]] ;
- **Comportement dynamique** (dynamic behavior) ;
- **Bruit et outliers** (noise and outliers) : la prise en compte du bruit et des points aberrants dans les données ;
- **Insensibilité à l'ordre d'entrée** (insensitive to the order of input) : un résultat qui ne dépend pas de l'ordre dans lequel les points sont fournis ;
- etc.

# Remarque

Pour un exemple de propriétés d'un algorithme de clustering, voir le [[k-means]] et ses [[Propriétés du k-means|propriétés]].
