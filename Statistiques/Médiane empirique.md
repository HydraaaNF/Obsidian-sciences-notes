# Définition
Pour un échantillon trié $x_{(1)} \leq \ldots \leq x_{(n)}$, la médiane est la valeur de l'individu du milieu.

Pour $n$ pair, on prend la moyenne des deux valeurs centrales : $\dfrac{x_{(n/2)} + x_{(n/2+1)}}{2}$

# Interprétation
Résumé de tendance centrale, beaucoup plus robuste aux valeurs aberrantes que la [[Moyenne empirique]].

# Remarque
Pour une distribution parfaitement symétrique, moyenne = médiane = [[Mode (statistique descriptive)|mode]].
